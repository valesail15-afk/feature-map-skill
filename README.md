# feature-map · 通用功能地图技能

让 Agent 回答「某功能在界面哪里、怎么点开」。技能只提供查询脚本和格式约定，**每个项目维护自己的地图数据**，接入新项目不需要改代码。

```powershell
python <skill目录>\scripts\fmap.py 设为壁纸
```

```
功能在哪里：壁纸详情 > 设为壁纸
怎么打开：打开壁纸详情 > 点「设为壁纸」> 选桌面/锁屏/桌面与锁屏同时设置
```

## 技能包内容

| 路径 | 作用 |
| --- | --- |
| `SKILL.md` | Agent 自动发现与调用说明 |
| `scripts/fmap.py` | 查询入口，可跨项目调用 |
| `examples/wallpaper-app.yaml` | 参考示例：壁纸推荐精选 App 的 27 条真实地图 |
| `examples/demo.yaml` | 最小格式示例（2 条） |
| `sites/hy.ithinkai.cn/feature-map.yaml` | 网站示例：红鸦 AI（登录后实跑取证的 75 条地图） |
| `sites/canvas.vbing.site/feature-map.yaml` | 网站示例：连镜（登录后实跑取证的 73 条地图） |
| `README.md` | 本文件，接入与维护说明 |

技能包内**不含任何项目数据**；`examples/` 只是参考，不会被自动加载。

## 接入一个新项目

1. **安装技能**（二选一，脚本不依赖安装位置）
   - 全局：把整个技能目录放到 `%USERPROFILE%\.trae-cn\skills\feature-map`，所有项目可发现。
   - 项目内：放到 `<项目>\.trae\skills\feature-map`，只对该项目生效。
2. **在项目根目录创建地图**（二选一）
   - 有现成地图：`copy <skill目录>\examples\wallpaper-app.yaml <项目根目录>\feature-map.yaml`
   - 从空白开始：新建 `feature-map.yaml`，先写 3-5 条最常用功能。
3. **在项目根目录查询验证**：

```powershell
python <skill目录>\scripts\fmap.py 功能名
```

改条目后无需重启，下一次查询立即生效。

## 数据文件定位规则

脚本按顺序查找，不依赖绝对路径：

1. `--data <路径>` 参数
2. `--site <域名>` 参数（技能内置站点地图 `sites/<域名>/feature-map.yaml`）
3. 环境变量 `FEATURE_MAP_FILE`
4. 从当前工作目录**向上逐级**查找 `feature-map.yaml`

因此在项目子目录里执行也能找到根目录的地图；同一项目有多份地图时用 `--data` 指定。

## 网站 / Web 产品怎么接

技能本身不按端区分：App、Web、桌面端都一样，只是「取证来源」和「地图放哪」不同。

1. 用浏览器登录目标网站，逐页记录左侧/顶部导航、按钮文案和进入步骤（登录需要人工扫码时由用户协助）。
2. 在技能目录建一个站点文件夹：`sites/<域名>/feature-map.yaml`，按本文格式写条目。
3. 查询时用 `--site <域名>`（网站没有代码仓库，不存在"项目根目录"）：

```powershell
python <skill目录>\scripts\fmap.py 充值 --site hy.ithinkai.cn
```

完整示例见 `sites/hy.ithinkai.cn/feature-map.yaml`（红鸦 AI，75 条：6 个主导航页及全部二级页、三级弹窗/子功能、案例详情与一键同款、产品档案、知识库、词库批量操作、4 个工具、套餐/充值记录、积分/申诉/流水、邀请/海报/规则、分销子页、开发者接入与插件安装、教程专题页、协议页）；`sites/canvas.vbing.site/feature-map.yaml`（连镜，73 条：左侧导航、创作页三种生成模式与参数、资产筛选、短剧/营销工作室、我的作品、画布编辑器节点与菜单、个人中心与积分商城）。

注意：登录页的表单可能是隐藏副本（`inert`），直接用选择器填写会超时；先点页面右上角「登录」激活登录面板再填。直接访问子路由也可能被 nginx 403，要从页面内导航点击进入。

未纳入取证的部分：实际支付流程、真实生成作品后的结果/编辑页（会扣积分或产生订单）；会员「规则」的跳转目标；词库导入/导出/批量删除与插件安装的实际执行结果。

注意：地图是取证时的快照，不实时爬取；网站改版后按"修改与删除"一节更新对应条目即可。如果该网站已有代码仓库，直接把地图放到仓库根目录改成 `feature-map.yaml`，就回到了标准用法。

## 数据格式

```yaml
features:
  - name: 设为壁纸                              # 功能名称，取界面实际文案，必填
    aliases: [设置壁纸, 换壁纸, 设为桌面, 设为锁屏]  # 常见别名，可选
    where: 壁纸详情 > 设为壁纸                    # 在哪里，必填，用 " > " 分隔层级
    how: 打开壁纸详情 > 点「设为壁纸」> 选桌面/锁屏  # 怎么打开，必填，用 " > " 分隔步骤
```

约定：

- `name` 与界面文案保持一致；入口文案和页面标题不一致时，两个说法都放进 `aliases`（示例：菜单叫「浏览历史」，页面标题是「浏览足迹」）。
- `where` 从顶层入口（底部导航 / 页面）逐级写到功能本身；同一功能有多个入口时，主路径写前面，备选入口放在 `how` 括号里。
- `how` 按点击顺序写，最后一步落到能看见或触发该功能的位置。
- 别名直接影响命中率，尽量覆盖用户的日常叫法。
- **名称与别名在全图内必须唯一**：同一功能有多个入口时合并成一条，把其他入口写进 `where`/`how`；不要让两个条目共用同一个名字或别名，否则查询会命中错误条目。
- 界面文案改版后，以新文案为 `name`，旧文案留在 `aliases`；例如「浏览足迹」改叫「浏览历史」时，保留旧叫法作为别名。

## 新增条目

1. 打开项目根目录的 `feature-map.yaml`。
2. 在 `features:` 下追加一条记录，缩进与已有条目一致（两个空格 + `- `）。
3. 保存后在项目根目录查询验证：`python <skill目录>\scripts\fmap.py 新功能名`。

```yaml
  - name: 语言设置
    aliases: [语言, 简体中文, 多语言]
    where: 通用设置 > 通用 > 语言
    how: 点「我的」> 齿轮 > 点「语言」
```

## 修改与删除

- 改名：改 `name`，旧名称保留在 `aliases` 里，避免老说法查不到。
- 界面改版：改 `where` / `how` 文本，并复跑一次确认。
- 删除：整条删掉（从 `- name:` 到该条最后一行）。

## 查询与返回约定

| 命令 | 行为 |
| --- | --- |
| `python ...fmap.py 壁纸详情` | 最佳匹配，输出两行 |
| `python ...fmap.py 我的 收藏` | 多关键词，需全部命中 |
| `python ...fmap.py 会员 --all` | 所有匹配项，带功能名 |
| `python ...fmap.py --list` | 列出全部功能及位置 |

匹配规则：名称/别名完全匹配优先，其次前缀、包含；多关键词各自打分累加；名称和别名都没命中时，再在 `where`/`how` 文本里兜底检索。

未命中：标准错误输出「未找到匹配的功能：X」，退出码 1。
找不到数据文件：提示创建 `feature-map.yaml` 或使用 `--data`，退出码 2。
